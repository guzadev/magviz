# MAG Studio — Página Web Oficial

MAG Studio es un estudio de visualización arquitectónica enfocado en la creación de imágenes, animaciones y recorridos interactivos que combinan sensibilidad estética, precisión técnica e impacto visual.

Este sitio fue desarrollado con **Next.js**, **Tailwind CSS** y está preparado para ser desplegado en **Vercel**.

---

## 🧩 Estructura del sitio

- **Inicio**: Presentación breve del estudio
- **Nosotros**: Filosofía, valores y herramientas utilizadas
- **Servicios**:
  - Renders Estáticos
  - Animaciones Arquitectónicas
  - Recorridos Interactivos (Kuula)
- **Proceso de Trabajo**: Explicación paso a paso del flujo de colaboración
- **Proyectos**: Galería (en desarrollo)
- **Contacto**: Información de contacto y formulario conectado con Resend

---

## 🚀 Tecnologías

- **Next.js** (App Router)
- **Tailwind CSS**
- **TypeScript**
- **Resend API** (para el envío de formularios)
- **i18n multilingüe**: Español / Inglés con sistema de traducción personalizado

---

## 🌐 Deploy

El proyecto está desplegado en [Vercel](https://vercel.com/), con soporte para SSR y CDN global.

---

## 📁 Organización del código

```
/app              → Páginas y rutas
/components       → Componentes reutilizables
/public           → Imágenes, logo, videos
/styles           → Configuración de Tailwind
/language-provider.tsx → Sistema multilingüe
```
